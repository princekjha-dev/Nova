# Nova Technology Decision Matrix

This matrix provides the comparative evaluation of candidate open-source technologies, analyzing their applicability to Nova across technical capability, licensing, platform compatibility, and architectural fitness.

| Technology | Nova Feature | Integration Method | Rust Ecosystem | Linux Compatibility | Android Compatibility | Security Profile | Performance Profile | License | Architectural Decision |
|---|---|---|---|---|---|---|---|---|---|
| **KDE Connect** | Cross-device features (clipboard, input, ping) | Protocol / Architecture Study | Third-party unmaintained crates (`kdeconnect-rs`) | Excellent (Qt/KDE runtime dependency) | Native app available | TLS with custom certificates | Low latency TCP/UDP | GPL-2.0-or-later | **REFERENCE ONLY** (Do not embed due to GPL copyleft; adopt clean modular plugin concept) |
| **scrcpy** | Android → Linux screen mirroring & touch | Embedded Server Binary (APK) + Custom Protocol Client | Scrcpy protocol spoken directly via Rust socket | Native C client / Linux Wayland/X11 | Precompiled Java/server binary run via ADB/app | Device pairing token / ADB authorization | 60+ FPS, <40ms latency, H.264/H.265 HW encode | Apache-2.0 | **ADOPT (EMBED SERVER)** (Highest-value screen mirroring integration in ecosystem) |
| **LocalSend** | File EasyShare | Protocol Implementation (LocalSend v2.1 REST/HTTPS) | `localsend-rs` reference crate available | Excellent (HTTPS REST) | Native app available | HTTPS with ephemeral certs / PIN | High throughput LAN chunked transfer | Apache-2.0 / MIT | **USE VIA PROTOCOL** (Implement wire-compatible REST/Chunking endpoints in Rust) |
| **Syncthing** | Continuous Folder Sync | Optional External Process / Service | `syncthing` Go binary, no direct Rust library | System daemon / user service | Available as separate app | TLS mutual auth with device IDs | Continuous file-level hashing & block sync | MPL-2.0 | **OPTIONAL BACKEND** (Defer to later phase for full-disk directory replication; not suitable for ad-hoc transfer) |
| **RustDesk** | Remote PC & screen streaming | Architectural Reference | Rust monorepo, proprietary server model | Linux X11/Wayland support | Client available | Custom encryption protocol | VP9/H.264 video streaming | AGPL-3.0 | **REJECT** (AGPL-3.0 network copyleft infects proprietary or Apache-2.0 code; build custom uinput pipeline) |
| **Sunshine** | Game & Desktop Host Streaming | Architectural Reference | C++ only, no Rust library | Linux (NVENC/VAAPI/software) | Client-only (Moonlight) | PIN + TLS handshake | Ultra-low latency NVENC/VAAPI | GPL-3.0 | **REJECT** (GPL-3.0 prevents embedding; study hardware encoder selection strategies) |
| **Moonlight** | Remote streaming client | Architectural Reference | C/C++ clients | Linux Qt/SDL client | Android native client | GameStream cryptographic handshake | Hardware-accelerated decoding | GPL-2.0 | **REJECT** (GPL-2.0 license restriction; implement custom lightweight RTP/WebRTC player) |
| **wayvnc** | Remote control on wlroots | Optional External Backend | C binary, uses NeatVNC | wlroots compositors only (Sway, Hyprland) | VNC clients | VNC auth / TLS | Framebuffer damage tracking | ISC / MIT | **USE AS OPTIONAL BACKEND** (Viable headless VNC server for wlroots environments) |
| **NeatVNC** | Fast VNC server library | Dynamic Library / C-FFI | C library | Linux Wayland/wlroots | N/A (Server-side) | TLS VNC | Damage region compression | ISC | **REFERENCE ONLY** (Avoid C linking complexities; prefer Portal + WebRTC) |
| **Weylus** | Tablet/Phone touch input injection | Architectural Reference | Rust codebase | Linux X11/Wayland via `uinput` | Browser-based client | WebSocket + Password | Low-latency canvas streaming | Apache-2.0 | **REFERENCE ONLY** (Adopt uinput virtual device patterns in `nova-plugins/remote`) |
| **Yjs** | Real-time collaborative state | Protocol standard | JS-native reference | Node/Browser | WebView / JS engine | Application-level | High-efficiency RLE state vectors | MIT | **USE VIA PROTOCOL** (Core CRDT wire standard) |
| **yrs** | Notes & Workspace CRDT Engine | Direct Rust Crate | Official Yjs port in Rust (`yrs`) | Native Linux Rust | Native Android via JNI / NDK | Memory safe (pure Rust) | Fast in-memory text updates, minimal memory footprint | MIT | **ADOPT** (Core synchronization primitive for notes, tasks, and collaborative workspaces) |
| **Automerge** | JSON document CRDT | Direct Rust Crate | Native Rust crate (`automerge`) | Native Linux Rust | Native Android Rust | Memory safe (pure Rust) | Excellent for structured JSON trees, heavier than Yjs for text | MIT | **ADOPT AS OPTIONAL BACKEND** (Primary for structured settings/tree sync; Yjs for text) |
| **snow** | Cryptographic Handshake | Direct Rust Crate | Pure Rust Noise Protocol Framework crate | Native Linux Rust | Native Android Rust | RFC 7539 ChaCha20Poly1305, BLAKE2s, X25519 | Zero-copy cryptographic handshakes | Apache-2.0 / MIT | **ADOPT** (Noise XX mutual authentication primitive for all Nova pairing & sessions) |
| **libp2p-noise** | P2P Noise transport | Direct Rust Crate | Rust crate within libp2p | Native Linux Rust | Native Android Rust | Standard Noise XX / IK | Pulls heavy libp2p dependency graph | Apache-2.0 / MIT | **REJECT** (Unnecessary dependency bloat; `snow` provides exact Noise primitive needed) |
| **Avahi / mDNS** | LAN Device Discovery | Dual Strategy: `mdns-sd` (crate) + D-Bus Avahi | Pure Rust `mdns-sd` crate | Avahi daemon via D-Bus (`zbus`) | Android `NsdManager` | Local multicast only; unauthenticated until Noise | Lightweight UDP multicast | LGPL-2.1 / MIT | **ADOPT** (Use `mdns-sd` pure Rust crate primary, fallback to Avahi system D-Bus) |
| **xdg-desktop-portal**| Wayland Screen Capture & Remote Desktop | D-Bus IPC (`ashpd` crate) | Pure Rust D-Bus bindings via `ashpd` | Standard Wayland security boundary (GNOME, KDE, wlroots) | N/A (Linux desktop host) | User consent prompts enforced by compositor | PipeWire stream negotiation | LGPL-2.1 | **ADOPT** (Mandatory standard for Wayland screen capture and remote desktop control) |
| **lamco-portal** | Wayland portal helpers | Reference Implementation | Rust crate | Wayland compositors | N/A | Portal-mediated | PipeWire file descriptor handoff | MIT | **REFERENCE ONLY** (Study portal negotiation patterns, link directly via `ashpd`) |
| **wlroots** | Headless virtual display | Compositor Protocol Interface | C library / Wayland protocol XML | Sway, Wayfire, Hyprland | N/A | Compositor privileges | Zero-copy buffer sharing | MIT | **ADOPT AS OPTIONAL BACKEND** (For true headless screen extension on wlroots compositors) |
| **GStreamer** | Multimedia encode/decode pipeline | Dynamic Library (`gstreamer-rs`) | High-quality Rust bindings | Standard Linux distro package | Native NDK support | Robust pipeline sandbox | VAAPI / NVENC / CPU hardware acceleration | LGPL-2.1 | **ADOPT (DYNAMIC LINKING)** (Hardware-accelerated Linux screen capture encode) |
| **FFmpeg (libav*)** | Fallback Codec Transcoding | Dynamic Library | C library with Rust wrappers | Universal Linux support | Android NDK support | Process boundary recommended | High performance CPU/GPU transcoding | LGPL-2.1 / GPL | **ADOPT AS OPTIONAL BACKEND** (Dynamic linking only to avoid GPL copyleft) |
| **WebRTC (webrtc-rs)**| Low-Latency A/V & Data Transport | Direct Rust Crate | Pure Rust async WebRTC stack | Native Linux Rust | Native Android Rust | DTLS-SRTP encryption, mandatory | Sub-100ms adaptive bitrate video over UDP | MIT / Apache-2.0 | **ADOPT** (Ultra-low latency transport for screen mirroring and WAN collaboration) |
| **SQLite (rusqlite)**| Local Persistence | Direct Rust Crate | Pure bundled Rust/C SQLite engine | Linux native | Android native | AES-GCM / SQLCipher optional | Zero-network ACID transactions, FTS5 token search | MIT / Public Domain | **ADOPT** (Core persistence for device registry, note documents, clipboard history, transfers) |
| **SQLx** | Async database access | Direct Rust Crate | Async Rust SQL driver | Linux native | Android NDK | Compile-time query verification | Async connection pooling | MIT / Apache-2.0 | **REFERENCE ONLY** (Too heavyweight for embedded single-user client; `rusqlite` bundled is ideal) |
| **libsecret** | Linux Secure Credential Store | D-Bus IPC (`secret-service` crate) | Pure Rust D-Bus client | Freedesktop Secret Service (GNOME Keyring, KWallet) | N/A (Android uses Keystore via JNI) | OS-managed keyring master key | Instant local IPC | LGPL-2.1 / MIT | **ADOPT** (Secure root-of-trust key storage on Linux) |
| **Tauri** | Linux Desktop Client Framework | Application Shell | Official Rust + Webview integration | WebKit2GTK on Linux | Android supported | Process isolation, capability IPC | 5–15 MB RAM, 10 MB binary (vs 200MB Electron) | MIT / Apache-2.0 | **ADOPT** (Standard desktop shell for Nova Linux application) |
| **uinput** | Linux Input Injection | Linux Kernel `/dev/uinput` | Standard kernel interface via `evdev` crate | Linux kernel 2.6+ | N/A (Host only) | Requires `input` group membership or udev rule | Zero-latency kernel-level mouse/keyboard events | Linux Kernel (GPL-2.0 syscall boundary) | **ADOPT** (Standard, license-safe mechanism for synthetic input in Remote PC) |
